Project

ALPHA CAR

AI vehicle consulting desktop application

Demo Video

Overview

ALPHA CAR is an AI vehicle consulting platform created from a real vehicle-consulting use case. It combines current vehicle information, real-time voice interaction, and personalized recommendations in a desktop application.

The system used web crawling and RAG for current vehicle information, GPT-4o-based consulting, Realtime API audio interaction, and Firebase-backed memo and calendar features.

My Role

  • Collected and processed vehicle specification data through web crawling.
  • Prepared data for retrieval-based vehicle information access.
  • Contributed to consultant response scenarios.
  • Developed Electron-based UI and presentation materials.

Key Features

  • Latest vehicle information retrieval
  • RAG-based consultation
  • Realtime Audio-to-Audio interaction
  • Personalized vehicle recommendations
  • Memo and calendar management
