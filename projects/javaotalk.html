JavaOTalk

Network-programming-based real-time chat application

GitHub

Overview

JavaOTalk is a desktop messaging application built around Java socket communication and multithreading. It extends basic messaging with group chat, friend management, emojis, profile customization, mini-games, voting, and other interactive functions.

My Role

  • Designed client UI/UX and developed front-end client functions.
  • Implemented chat-room management, invitations, notifications, and theme-related interactions.
  • Designed and implemented mini-game and voting functions.
  • Prepared project reports and presentation materials.

Key Features

  • Login and registration
  • Real-time one-to-one and group chat
  • Online / offline friend status
  • Chat-room creation and management
  • Emoji sending
  • Profile customization and interactive features
