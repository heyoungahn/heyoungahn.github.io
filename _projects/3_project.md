**2024–2025 · Industry Collaboration: maum.ai · CAR321**

An AI desktop vehicle consulting platform designed to provide real-time conversational assistance, current vehicle information, and personalized recommendations.

The project combines vehicle-data crawling, **RAG**, prompt engineering, GPT-4o, and Realtime API-based voice interaction. My work included vehicle-data crawling and processing, Electron UI development, consulting-scenario design support, and presentation materials.

**Tech:** Electron · React · GPT-4o · RAG · Realtime API · Firebase
