# Heeyoung Ahn — Personal Academic Website

Static personal website for **Heeyoung Ahn**, M.S. Student at AML Lab, Hansung University.

## Structure

- `index.html` — About
- `research.html` — Current research
- `projects.html` — Projects
- `publications.html` — Publications and academic outputs
- `cv.html` — CV
- `assets/css/style.css` — Site styles
- `assets/js/main.js` — Mobile navigation

This site intentionally uses plain HTML, CSS, and JavaScript with no framework or build step.
