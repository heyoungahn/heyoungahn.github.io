G-Vision Chatbot

Industrial LLM Interface for Equipment Software

LLM EXAONE · Flask · C# / WPF

Overview

An industrial LLM interface that connects an EXAONE-based local LLM to C# WPF equipment software through a Flask API. The project explored how natural-language input can be translated into structured equipment interactions while keeping inference local.

Project Scope

  • Natural-language input for equipment interaction
  • Local LLM inference using EXAONE and llama.cpp
  • Flask API bridge between the LLM and C# WPF software
  • JSON-based command exchange for equipment functions
  • Inspection / recipe information assistance and execution-error analysis
  • Operator training and equipment-operation support

Tech Stack

EXAONE llama.cpp Flask C# WPF JSON Local LLM
