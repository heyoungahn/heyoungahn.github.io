Tennis Court Reservation App

iOS and Android tennis court reservation application

GitHubDemo Video

Overview

A university tennis-court reservation application implemented across iOS and Android. The project supports reservations, competition registration, notices, account management, and map-based navigation, with Firebase used for real-time data management.

My Role

  • Developed the full iOS application using Swift and UIKit.
  • Implemented core Android reservation, login, and notice functionality.
  • Integrated Firebase for reservation and competition data.
  • Designed UI/UX and implemented map navigation.
  • Implemented duplicate-reservation and booking-limit logic.

Key Features

  • Login and registration
  • Court reservation with date/time constraints
  • Competition registration
  • Notice board
  • MyPage reservation management
  • Map-based navigation
