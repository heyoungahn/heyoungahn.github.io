Project

Flower POS & Vending Machine

Integrated flower POS and self-service vending system

🌷POS + Vending

Overview

The project implements a combined sales system for customized flower bouquets. Users can select flowers, decorative greenery, wrapping, purpose, and design, while the system supports both a seller-oriented POS workflow and a consumer-oriented vending-machine workflow.

My Role

  • Contributed to bouquet ordering and UI flow design.
  • Worked on POS and vending-machine interaction scenarios.
  • Contributed to payment, membership/points, database, and sales-management functions.
  • Prepared project documentation and UI flow materials.

Key Features

  • Custom bouquet configuration
  • POS order and inventory workflow
  • Self-service vending flow
  • Cash and card payment
  • Point accumulation and use
  • Daily and monthly sales management
