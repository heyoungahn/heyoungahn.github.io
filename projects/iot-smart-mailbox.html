IoT-based Smart Mailbox

Real-time mailbox monitoring with IoT, web, and cloud integration

Demo Video

Overview

This project detects mail arrival using an ultrasonic sensor and provides real-time monitoring through a React web application. Sensor data is transmitted through MQTT, while recent and favorite mail records are managed with Firebase Firestore.

My Role

  • Designed and assembled the Raspberry Pi and ultrasonic-sensor hardware.
  • Implemented MQTT-based sensor-data transmission.
  • Developed the React web application and real-time rendering.
  • Implemented Firebase CRUD and favorites management.
  • Designed the interface in Figma.

Key Features

  • Real-time mail arrival detection
  • MQTT communication
  • React-based monitoring UI
  • Firestore data storage and synchronization
  • Search and favorites
