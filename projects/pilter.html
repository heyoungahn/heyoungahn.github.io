Pilter

AI pill recognition and medication assistance application

GitHub

Overview

Pilter is a medication-assistance application designed to support safer medication use and reduce unnecessary medication disposal. A camera image is processed with a YOLOv8 + CoreML recognition pipeline, and the app provides medication information, pharmacy search, reminders, and chatbot assistance.

My Role

  • Developed the iOS UI/UX.
  • Implemented Naver Map API integration for nearby pharmacy search.
  • Implemented medication management and reminder functions.
  • Supported project documentation and presentation materials.

Key Features

  • YOLOv8 pill recognition
  • Medication dosage, side-effect, and precaution information
  • Nearby pharmacy search
  • Gemini-based ChatPill chatbot
  • Medication reminders and history management
